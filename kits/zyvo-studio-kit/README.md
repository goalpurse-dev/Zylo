# Zyvo Studio Kit (free)

Make an "In This Town" story short in your own Roblox Studio with Claude Code. Free; nothing leaves your computer
except what Claude Code and Roblox Studio normally send.

- `SKILL.md`: the skill Claude Code follows.
- `reference/`: setup, story writing, shot list rules, recording.
- `luau/`: small Studio helpers the skill runs (blockout, spots, asset check + clean, cast, lighting, shot list,
  director installer). `runtime/`: the two scripts that run the camera and the actions during Play.
- `scripts/system_check.*`: can this computer do it?

Install: copy this folder to `~/.claude/skills/zyvo-studio-kit`, turn on "Enable Studio as MCP server" in Studio
(Assistant > ... > Settings > MCP Servers), connect Claude Code (Quick connect), then ask Claude Code to make an In This
Town video.

The kit never saves or publishes your place, never uses paid items, and never adds audio. Want the voice, captions,
sound and music done for you? Finish in Zyvo: https://www.tryzyvo.com/in-this-town-story-video-maker
